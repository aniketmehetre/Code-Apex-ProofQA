# ProofQA 2.0: The Verification-Native Autonomous QA Engineer

> **Team VOID MAIN** | Code Apex, Track 2: Autonomous AI QA Engineer

ProofQA 2.0 does not file mere bug opinions. It produces **Bug Certificates**: self-contained, machine-checkable proof objects that anyone can independently re-verify in a clean container with one command.

## Quickstart

```bash
# Setup dependencies and playwright browsers
make setup

# Run linter and tests
make lint
make test

# Start the shop twin target app
make twin

# Run the benchmark
make bench

# Run the end-to-end demo
make demo
```
